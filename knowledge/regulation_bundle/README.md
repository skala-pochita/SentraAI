# 배포용 규제 원문 · RAG 스냅샷

이 디렉터리는 Git과 백엔드 Docker 이미지에 함께 포함한다. 새 설치는 개인 원문 등록이 없을 때 이 자료의 원문·연결·SQLite 검색 인덱스를 자동으로 사용한다. 컨테이너에 마운트되는 `knowledge/sources`와 별도 경로이므로 빈 CLI 원문 디렉터리가 배포 자료를 가리지 않는다.

`sources/MANIFEST.yaml`에 문서별 출처·버전·취득 경로·해시가 있으며, `INVENTORY.json`은 배포 파일 전체의 SHA256 목록이다. `config/links/bundled.yaml`은 원문과 인용을 대조한 관련성 후보이며 법적 적용이나 사람의 확인 완료를 뜻하지 않는다.

## 포함 자료

- 인공지능기본법: 국가법령정보센터 2026-07-21 시행 본칙. 부칙·별표 제외. 공식 HTML과 추출 TXT 보존.
- 인공지능기본법 시행령: 국가법령정보센터 2026-08-20 시행 본칙. 부칙·별표 제외. 공식 HTML과 추출 TXT 보존.
- 금융분야 인공지능 가이드라인: 금융위원회 2026-06-18 공개 PDF.
- 금융분야 인공지능 보안 안내서: 2026-06 공개 PDF. 발행처 서버 연결 오류로 KMS Technology 공개 재게시 첨부에서 취득했으며 발행처 파일과의 바이트 동일성은 확인하지 않았다. 취득 경로를 매니페스트에 명시한다.
- 고영향 인공지능 사업자 책무 가이드라인: 한국인공지능·소프트웨어산업협회 공개 첨부 PDF.
- AI RMF 보도자료: KDI 정책자료 아카이브 보관본. 참고 자료이며 규제 검색에 넣지 않는다. AI RMF 본문은 포함하지 않는다.

PDF 원본·텍스트·Markdown·조항 파일과 출처를 함께 보존한다. PDF 추출물의 서식은 원본과 다를 수 있다. 이 스냅샷은 명시된 버전을 고정하며 이후 개정 사항을 자동 추적하지 않는다.

## 동작

- 최초 설치에서 추가 다운로드·색인 명령·모델 키 없이 규제 검색과 보고서 연결을 사용할 수 있다.
- 배포 인덱스는 hash-v1 임베딩과 키워드 점수를 사용하는 오프라인 검색이다. OpenAI 의미 임베딩 인덱스가 아니며, 모델 키 설정 여부와 관계없이 같은 인덱스를 사용한다.
- 사용자가 `knowledge/sources/MANIFEST.local.yaml`로 자신의 원문을 반입하면 해당 로컬 자료가 우선한다. 기존 원문과 검토 기록을 자동 덮어쓰지 않는다. 사용자 자료는 기존 절차로 색인·연결을 준비한다.
- `REGULATION_INDEX_PATH`를 명시하면 해당 인덱스 설정을 우선한다. 원문 스냅샷과 일치해야 한다.
- 이미 생성한 보고서는 자동 변경하지 않는다.

관리자가 실제 원문과 연결을 갱신하고 검증한 후 `backend/.venv/Scripts/python.exe scripts/build_regulation_bundle.py`(Windows) 또는 `backend/.venv/bin/python scripts/build_regulation_bundle.py`(Linux/macOS)로 배포 스냅샷을 재생성한다. 신규 파일은 출처와 해시를 검토한 뒤 커밋한다.
