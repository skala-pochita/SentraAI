# OWASP Agentic AI 위협 요약

> 팀 요약본. 에이전트 매니페스트(도구·권한·프롬프트) 정적 점검과 결합 위험 판정의 근거.

## T1 메모리·컨텍스트 오염 (Memory Poisoning)
정의: 장기 메모리·RAG 문서·대화 이력에 악성 지시를 심어 이후 행동을 조작.
대응: 외부 문서는 데이터로만 취급, 출처 표시, 메모리 쓰기 권한 제한.

## T2 도구 오남용 (Tool Misuse)
정의: 인젝션 등으로 조작된 에이전트가 정당한 도구를 악의적으로 사용 (삭제, 환불, 발송).
예시: 간접 인젝션 문서를 읽은 CS 에이전트가 `delete_customer` 를 승인 없이 실행.
대응: 파괴적·외부 전송 도구는 사람 승인 필수, 도구별 입력 검증, 호출 횟수 제한.

## T3 권한 침해 (Privilege Compromise)
정의: 에이전트에 부여된 넓은 권한이 공격자 권한이 되는 문제. 다른 고객 데이터 조회 등.
대응: 요청자 컨텍스트 기반 권한(본인 데이터만), 최소 스코프, 자격증명 분리.

## T6 의도 조작 (Intent Breaking & Goal Manipulation)
정의: 다단계 대화·역할극으로 에이전트의 목표를 바꾸는 공격.
대응: 지시 계층 고정, 민감 행동 전 재확인, 대화 단위 이상 탐지.

## T9 신원·자격증명 위장 (Identity Spoofing)
정의: "관리자 요청이야" 처럼 권한을 사칭하거나, 에이전트 자격증명이 코드에 하드코딩되어 탈취됨.
대응: 권한은 대화 내용이 아니라 인증 컨텍스트로 판단, 에이전트 키는 비밀 저장소에서 주입.

## 결합 위험 (Combined Risk) 판단 기준
인젝션에 뚫리는 에이전트 + 승인 없는 삭제·쓰기 도구 = 데이터 파괴 가능(CRITICAL).
외부 전송 채널 + 유출 성공 = 외부 유출 경로(CRITICAL). 에이전트 키가 코드에도 하드코딩 = 자격증명 노출(CRITICAL).
