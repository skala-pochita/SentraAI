## 1. 매핑 검토

### 검토 기준

- 인용이 해당 원문에 실제로 존재하는가?
- 현재 탐지 규칙이 알아내는 사실과 조항의 통제가 같은가?
- AI·금융·고영향·고객 영향 등 적용 전제가 빠지지 않았는가?
- 단발 감사로 정기 운영·조직 의무를 확인했다고 오인하게 만들지 않는가?

### 보류한 8개

| 기존 연결 | 보류 이유 |
|---|---|
| INFO_EXPOSURE → 모델 정보 노출 방지 | 실제 규칙은 일반 스택트레이스 노출도 탐지함. 모델 정보 노출이라고 가정할 수 없음 |
| SECRET_LEAK → API 키 안전 보관 | 실제 규칙은 AWS 키·JWT·개인키도 탐지함. AI API 키 전용 근거와 일괄 연결 불가 |
| HARDCODED_SECRET → API 키 안전 보관 | 고엔트로피 비밀 문자열만으로 API 키·AI 자격증명 여부를 확인할 수 없음 |
| HARDCODED_CREDENTIAL → API 키 안전 보관 | 일반 DB 비밀번호도 포함되므로 API 키 항목과 일괄 연결 불가 |
| PROMPT_SECRET_EMBEDDED → API 키 안전 보관 | 프롬프트 안 기밀 문자열이 API 키라는 전제가 확인되지 않음 |
| AGENT_SHARED_SECRET → 서비스별 API 키 분리 | 코드·에이전트의 같은 환경변수 이름만으로 키 분리 위반을 입증할 수 없음 |
| TOOL_EXFIL_CHANNEL → 외부 도구 사전 승인 | 수신자 도메인 제한과 도구 도입 전 승인은 서로 다른 통제 |
| TOOL_MISUSE → 최소 권한 | 도구 오남용이 항상 권한 과다를 의미하지 않음 |

보류한 연결은 AI 검토에 따른 `review_required`로 남긴다. 실제 사람이 기각한 상태로 저장하지 않는다. 보안 Finding 자체는 유지하며 관련성·적용 전제의 추가 확인이 필요하다고 표시한다.

### 수정한 11개

| 수정 유형 | 개수 | 내용 |
|---|---:|---|
| 인용 보완 | 5 | 대상 설명만 인용하던 부분을 방어·검토·차단 기능까지 포함하도록 확대 |
| 점검 범위 수정 | 3 | 정기 모의훈련·운영 검증을 조직 증적 필요 항목으로 변경. 고영향·고위험 조건도 보완 |
| 적용 조건 보완 | 1 | 고객 영향도가 큰 금융 의사결정이라는 조건을 명시 |
| 연결 원문 교체 | 2 | 역할별 권한 대신 외부 AI 서비스 연결 권한 문구, 도구 사전 승인 대신 오남용 위험 완화 문구로 교체 |

나머지 9개는 조건과 한계를 명시한 관련성 후보로 유지했다. 사람 감독·증적 보관 등 조직 의무는 여전히 코드 검사만으로 확인할 수 없는 항목이다.

## 2. 프런트 의존성과 빌드

`package.json`과 `pnpm-lock.yaml`에는 이미 `three@0.170.0`, `@types/three@0.170.0`이 선언돼 있었으나 설치된 의존성에 빠져 있었다.

- 기존 작업 폴더의 공유 의존성 링크를 분리했다.
- 누락된 8개 패키지를 잠금 파일에 고정된 버전으로 확보했다.
- 패키지 압축 파일의 SHA-512를 잠금 파일의 integrity와 대조했다.
- 이 작업 복사본에만 설치했고, 패키지 버전·잠금 파일은 변경하지 않았다.
- **`npm run build` 통과**: vue-tsc 타입 검사와 Vite 프로덕션 빌드 완료.

500kB를 넘는 번들에 대한 Vite 크기 경고는 남아 있다. 빌드 오류는 아니며 이번 규제 리포트 화면의 실패로 분류하지 않았다. 일반 패키지 설치 명령은 환경의 네트워크 제한으로 실패해 잠금 파일 무결성을 확인한 개별 패키지 복구 경로를 사용했다.

## 3. 실제 브라우저 화면 검사

환경: 빌드된 Vue 화면 + 로컬 테스트 API 응답 + 실제 Chrome. **운영 DB나 실제 로그인 세션을 사용한 통합 테스트는 아니다.** 보고서 내용은 실제 5종 원문과 합성 에이전트 설정으로 생성한 스냅샷이다.

| 원문/미리보기 전환 | 통과 |
| JSON 다운로드 파일과 저장 보고서 스냅샷 비교 | 일치 |

다운로드 이벤트 관측 API는 시간 초과가 났지만 실제 파일은 생성됐다. 생성된 JSON과 MD 파일을 직접 읽어 저장된 보고서와 비교했다. 단순 버튼 클릭만으로 다운로드 검증 완료라고 기록하지 않았다.
