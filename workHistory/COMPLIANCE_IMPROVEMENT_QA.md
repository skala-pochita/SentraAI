## 데이터와 연결 수의 의미

- 원문은 **근거 5종 + 참고 보도자료 1종 보관**이다. 참고 보도자료는 규제 근거 검색에 들어가지 않는다.
- 392개 원래 단위에 정확한 원문 구간 9개를 추가해 **401개를 보존**한다.
- 기본 검색 후보는 실제 체크리스트 99개 + 원문 구간 9개 = **108개**다. 조직 차원의 항목도 포함되지만 코드만으로 확인했다고 표시하지 않는다.
- 법령의 다른 조항이나 미분류 페이지는 원문 저장·정확 조회를 유지하면서 자동 근거 검색에서 제외한다. 이번 기능 범위를 넘는 법령 검색 서비스는 완성하지 않았다.
- 활성 매핑은 **28개**, 보류한 기존 페이지 연결은 **10개**, 사람 확인 완료는 **0개**다.
- 새로운 Python 취약점 탐지기는 추가하지 않았다.

## 실행 안내

프로젝트 루트에서 백엔드 의존성이 설치된 Python을 사용한다.

```bash
# 의존성 설치는 backend 폴더의 pyproject.toml·잠금 파일을 따른다.
# 아래 <backend-python>은 해당 가상환경 Python 경로로 바꾼다.
<backend-python> scripts/qa_compliance_evidence.py
python3 scripts/corpus_search.py --verify
python3 scripts/corpus_search.py '외부 도구 사전 승인'
```

`scripts/qa_compliance_evidence.py`는 비용이 발생하는 모델 호출 없이 오프라인 hash-v1 인덱스를 검사하고 `reports/compliance-improvement/`에 결과를 만든다. 테스트 원문·색인·생성 링크는 기존 정책에 따라 Git 추적 대상에서 제외했다. 다른 장비에서 실행하려면 해당 로컬 자료를 함께 반입해야 한다.

원문 개정 시에는 PDF/텍스트/MD를 재반입하고 원문 구간과 연결을 다시 검토해야 한다. 정책 재생성 도구는 과거 정책을 적용하지 않은 원문에서 다시 구간을 추출한다. 기존 사람이 검토한 링크는 source hash가 달라지면 활성 연결로 사용하지 않고 재검토 대상으로 남긴다.
