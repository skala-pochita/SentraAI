# Cloud 평가셋 출처 기록

현재 `inputs/*.json` 15개(D01~D03, T01~T08, T01A·T06A 공격 변형, T01R·T06R 수정본)는 `scripts/build_cloud_datasets.py`
로 만든 **합성 사례**다. IAM Vulnerable·TerraGoat·DVMCP·MCPTox 의 위험 패턴(과도한 와일드카드 권한, 열린 보안 그룹,
공개 버킷, 승인 없는 삭제 도구, 도구 설명 오염)을 참고하되 자원명·표현을 바꿔 새로 작성했다.

| 항목 | 상태 |
|---|---|
| 공개 자료 commit 해시·라이선스 | **미확인** (착수 전날 준비 항목, 담당 4). 확인 전에는 "공개 자료에서 추출"이라고 주장하지 않는다 |
| 정답 1인 작성 + 다른 1인 확인 | **미수행** (작성자 1명 — 정답은 생성 스크립트와 `core/cloud/checks.py` 결정론 기준선으로 자체 점검만 했다) |
| 개발셋/최종셋 위험 패턴 계열 분리 | **미흡**: D01~D03 과 T01~T08 이 같은 패턴 계열을 일부 공유한다. 프롬프트 조정은 D 계열로만 한다 |
| 정답 위치 | `datasets/ground_truth/cloud/` (Agent·RAG·도구 경로에 노출 금지) |

정답 작성자 노출: 이 정답셋은 점검 로직과 같은 사람/에이전트가 작성했다. 독립 시험으로 주장하지 않는다.
